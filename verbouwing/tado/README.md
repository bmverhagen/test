# Tado / zone-regeling

Aankooponderzoek voor Tado X bij deze verbouwing (Nest vervangen, Vaillant CV, radiatoren + 3 VV-zones).

## Beoogde setup

- 1× Wired Smart Thermostat X (woonkamer, bestaande Nest-kabel, Vaillant)
- 7× Smart Radiator Thermostat X
- 3× Wireless Smart Thermostat X Starter Kit (één per vloerverwarmingsruimte)
- Bridge X optioneel (zit vaak in een bundle)
