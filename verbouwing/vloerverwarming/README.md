# Vloerverwarming

Materiaallijst en inkoop-BOM voor **30 m²** vloerverwarming op **beton**, max. opbouwhoogte **30 mm**.

## Bestand

- [`Materiaalbenodigdheden_Vloerverwarming.xlsx`](Materiaalbenodigdheden_Vloerverwarming.xlsx) — complete calculator (parameters, boodschappenlijst, verzending, regeling-keuze)

## Uitgangspunten

| Parameter | Waarde |
| --- | --- |
| Oppervlak | 30 m² (schaalt via Parameters) |
| Groepen | 4 |
| Zones | 3 ruimten apart regelen |
| Ondergrond | Beton |
| Max. opbouw | 30 mm |
| Systeem | MAGNUM SlimFit 12 + PE-RT 12×1,5 mm + Kreisel 418 vezel-egaline (~22 mm) |
